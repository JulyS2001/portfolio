Sobre mí

Soy estudiante de la Licenciatura en Sistemas en la Universidad Nacional de Lanús, enfocado en seguir creciendo profesionalmente dentro del desarrollo de software.

Cuento con experiencia en el desarrollo de aplicaciones web, trabajando en frontend con React y JavaScript, y en backend con Java y Spring Boot. También tengo conocimientos en bases de datos MySQL y utilizo Git y GitHub para el control de versiones y el trabajo colaborativo.

Me interesa participar en proyectos donde pueda aportar soluciones, enfrentar nuevos desafíos y continuar fortaleciendo mis conocimientos técnicos.
